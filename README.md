# second-project-mini-calculator.
# 🧮 Modern Calculator

A beautiful, modern, and fully functional calculator application built with **HTML**, **CSS**, and **JavaScript**.  
This calculator features a stunning glassmorphism UI design, smooth animations, keyboard support, and all basic arithmetic operations.

---

## 🚀 Live Demo

> Simply open `index.html` in any modern web browser to start using the calculator.

---

## ✨ Features

### 🎨 User Interface
- **Glassmorphism Design** – Modern frosted glass effect
- **Gradient Background** – Beautiful purple to pink gradient
- **Smooth Animations** – Button hover and click effects
- **Fully Responsive** – Works perfectly on all devices (desktop, tablet, mobile)

### 🧮 Functionality
- ✅ **Basic Operations** – Addition (+), Subtraction (-), Multiplication (×), Division (÷)
- ✅ **Decimal Support** – Perform calculations with decimal numbers
- ✅ **Clear Display** – Reset everything with 'C' button
- ✅ **Delete Last Character** – Remove last entered digit with '⌫' button
- ✅ **Error Handling** – Prevents division by zero and invalid expressions

### ⌨️ Keyboard Support
| Key | Action |
|-----|--------|
| `0-9` | Enter numbers |
| `+ - * /` | Enter operators |
| `.` | Enter decimal point |
| `Enter` or `=` | Calculate result |
| `Escape` | Clear all |
| `Backspace` | Delete last character |

### ⚡ Additional Features
- **Real-time Display** – Instant feedback on button press
- **Operator Replacement** – Automatically replaces last operator if changed
- **Floating Point Precision** – Rounds results to 10 decimal places
- **Responsive Layout** – Adapts to different screen sizes

## 🧪 How to Run Locally

### Method 1: Direct Open
1. Download all three files (`index.html`, `style.css`, `script.js`)
2. Save them in the **same folder**
3. **Double-click** `index.html`
4. Calculator will open in your default browser

### Method 2: VS Code Live Server
1. Open folder in VS Code
2. Right-click on `index.html`
3. Select **"Open with Live Server"**
